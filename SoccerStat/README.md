# SoccerStat

Веб-приложение для просмотра футбольной статистики: лиги, команды и календари матчей.

Проект выполнен в формате тестового задания, но структура и подход к разработке ориентированы на использование в коммерческой среде: с разделением логики по слоям, типизацией, работой с внешним API, обработкой ошибок и подготовкой к деплою.

## О проекте

`SoccerStat` — это SPA-приложение для просмотра футбольных соревнований и команд.

Пользователь может:
- посмотреть список лиг;
- найти нужную лигу по названию;
- открыть календарь выбранной лиги;
- отфильтровать матчи по диапазону дат;
- посмотреть список команд;
- найти нужную команду;
- открыть календарь выбранной команды;
- просматривать матчи с переводом времени в локальную временную зону.

Интерфейс реализован на русском языке.

## Основной функционал

### Лиги
- вывод списка лиг;
- поиск по названию;
- пагинация;
- карточка лиги с названием и страной;
- переход на страницу календаря лиги.

### Календарь лиги
- хлебные крошки;
- фильтр по дате "с / по";
- таблица матчей;
- отображение даты, времени, статуса, команд и счета;
- фильтрация по датам через API;
- отображение только тех частей счета, которые не равны `null`.

### Команды
- вывод списка команд;
- поиск по названию;
- пагинация;
- карточка команды с логотипом и названием;
- переход на страницу календаря команды.

### Календарь команды
- хлебные крошки;
- фильтр по дате;
- таблица матчей;
- пагинация.

## Работа с API

В качестве источника данных используется публичное API `football-data.org`.

Особенности реализации:
- запросы выполняются через `Axios`;
- API-токен хранится в `.env`;
- реализована обработка ошибок API;
- учитываются ограничения публичного тарифа;
- время матчей переводится из UTC в локальное время пользователя с помощью `dayjs`.

## Обработка ошибок

В проекте предусмотрены базовые сценарии обработки ошибок:
- отсутствует токен API;
- превышен лимит запросов;
- нет доступа к данным;
- ошибка сервера;
- таймаут запроса;
- пустой список данных.

Для пользователя выводятся понятные сообщения, без технического мусора.
